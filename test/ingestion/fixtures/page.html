Widgets

Widgets are the composable rendering unit of the system, and this page walks through creating one, mounting it into a host container, and the reference list of every supported lifecycle attribute on the element.

Creating widgets

Create a widget by registering its tag name with the runtime and providing a render function; the runtime instantiates it lazily the first time the tag appears in a container it controls anywhere on the page.

widget:mount

The mount event fires exactly once per instance after the first render completes, and handlers registered for it receive the host element so they can wire up observers or timers that the unmount event later disposes.
