# Pikelet

Pikelet builds semantic search artifacts that can be moved, hosted, range-read, verified, and queried without rebuilding the original index. The current focus is the complete `.pikelet` profile: index, corpus rows, query encoder declaration or inline encoder, calibration metadata, and evaluation data in one file.
